# Inception — User Documentation
*This activity has been created as part of the 42 curriculum by ehazizi.*

## What services are provided
This project provides a wordpress server with a database using mariadb and a revers proxy provided by nginx 
## how to start and stop activity
- Start using the `make` or `make all` command 
- Stop using Ctrl + c or `make down`
## Access website and admin panels
- https://login.42.fr
- https://login.42.fr/admin-wp
## locate and managed credentials 
- All credentials are managed by docker secrets and .env file which are need to be created for each use
## Check services if running correctly
- Using the command `docker ps` or by using docker GUI to check running services
